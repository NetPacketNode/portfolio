CyberScope

Разведочный инструмент: Nmap-скан портов, перебор поддоменов по DNS, отчёты в HTML, JSON и PDF, веб-дашборд с живыми обновлениями. Использовать только на системах, на тестирование которых есть письменное разрешение.

Сканирование без подтверждения разрешения не запускается. Это сделано намеренно.

1. Требования

  • Windows 10/11, Python 3.10 или новее
  • Nmap установлен и добавлен в PATH
  • для PDF-отчёта: pip install fpdf2

2. Установка

Распакуйте проект, откройте PowerShell в его папке и проверьте Nmap:

cd C:\Users\User\Desktop\cyberscope
nmap --version

3. Запуск скана из командной строки

python -m cyberscope 192.168.1.10 --ports 22,80,443 --i-have-permission

Флаги:

  • --i-have-permission — обязательный, подтверждает разрешение на тестирование
  • --ports — список или диапазон портов, по умолчанию 1-1000
  • --domain example.com — перебор поддоменов по DNS
  • --wordlist words.txt — свой список меток, по одной в строке (строки с # пропускаются)
  • --out report.html — HTML-отчёт, по умолчанию report.html
  • --json result.json — экспорт результатов
  • --pdf report.pdf — PDF-отчёт (нужен fpdf2 и шрифт Arial)

Полный пример:

python -m cyberscope example.com --domain example.com --wordlist words.txt --pdf report.pdf --json result.json --i-have-permission

4. Веб-дашборд

python -m cyberscope --serve

Откройте http://127.0.0.1:8765. Введите цель, при желании домен и порты, отметьте галочку разрешения и нажмите «Сканировать». Таблицы, сводка и диаграмма сервисов обновляются каждые 1,5 секунды. Сервер слушает только 127.0.0.1, из сети он недоступен. Порт меняется флагом --port.

5. Тесты

python -m unittest discover -s tests -v

6. Частые проблемы

  • «nmap не найден в PATH» — установите Nmap и перезапустите PowerShell.
  • «Отказ: укажите --i-have-permission» — флаг обязателен, добавьте его в конец команды.
  • Ошибка PowerShell «Отсутствует выражение после унарного оператора» — команда разбилась на строки. Вставляйте её целиком или ставьте обратный апостроф ` в конце каждой строки.
  • PDF не создаётся — установите fpdf2 и проверьте, что есть файл C:\Windows\Fonts\arial.ttf.
  • Дашборд не открывается — проверьте, что порт 8765 не занят, или укажите другой через --port.

7. Этика

CyberScope создан для учебной и авторизованной работы. Сканируйте только свои машины, стенды и цели с письменным разрешением владельца.
